# Surge 方案

Surge 模块用于 iOS 和 macOS，把本机直连出口所在的 /24 加入白名单。模块参考 [reallinzc/po0fw@7b99973](https://github.com/reallinzc/po0fw/tree/7b99973) 的做法重新编写，只保留 Surge 用到的部分。

## 安装

1. 把 `po0fw.sgmodule` 和 `po0fw.js` 放进 Surge 的配置目录。模块里的 `script-path` 是相对路径。配置放在 iCloud 时可以用 `surge/deploy.sh`，它只在内容变化时覆盖这两个文件。
2. 在 Surge 里启用「po0 防火墙加白」模块，按下表填参数。
3. 确认参数没有写进模块文件，否则下次覆盖会丢掉它。用 `cmp` 比较仓库里的 `po0fw.sgmodule` 和配置目录里的副本，应当一致。
4. 用过上游模块的，停用它，避免请求量翻倍。在 macOS 上可以用 `surge-cli script list | grep -i po0` 确认只剩 `po0fw-cron`、`po0fw-event`、`po0fw-panel`。

## 参数

| 参数 | 说明 | 示例 |
|---|---|---|
| `tokens` | `pgnfw_` token，多个用英文逗号分隔。`@槽位` 固定槽位 | 手机 `pgnfw_xxx@0`，家里的设备 `pgnfw_xxx@1` |
| `skip_ssid` | 连着这些 Wi-Fi 时不请求，多个用英文逗号分隔。不能含 `&` 和 `,` | 手机填家里的 Wi-Fi 名。常驻家里的设备留空 |
| `cron` | 定时检查的 cron 表达式，默认 `*/10 * * * *` | 作备份的设备用 `7,37 * * * *` |
| `notify_update` | 填 `1` 时推送加白结果，包括第一次成功和之后的网段变化。默认 `0` | 想知道加白情况时打开。手机用蜂窝时网段变化频繁，推送会多 |

同一个 token 的所有设备共用限频额度。家宽已经由路由器维护时，家里的备份设备把 `cron` 调低，并和路由器的整 5 分钟错开。

## 通知

状态按 token 记 ok 或 fail，只在状态变化时通知。换 token、增删 token 或调整顺序后重新记录，不沿用旧 token 的状态。

- 有 token 变成失败时通知一次。错误措辞变化不再通知。
- 从失败恢复到全部成功时通知「已恢复」。
- 网络错误、5xx（重试用尽）和 429 算暂时性错误。面板显示红色，但不改状态、不通知。
- 加白成功默认不通知。`notify_update=1` 时，打开后第一次成功推送当前网段，之后网段变化推送「旧 → 新」。403 pinned 和加白未生效不算。关掉开关会清空记录，再打开时重新从第一次算。

推送标题都是「🛡️ po0 防火墙加白」。示例为槽位 0：

| 情况 | 副标题 | 正文 |
|---|---|---|
| 变成失败 | 🚨 加白失败。多个 token 时为「🚨 1/2 个 token 加白失败」 | 每个 token 一行，例如 `📌0 ❌ HTTP 400 …`，末行 `🌐 出口 …` |
| 从失败恢复 | 🎉 已恢复 | `📌0 ✅ 已加白`，末行 `🌐 出口 …` |
| `notify_update=1`，第一次成功 | ✅ 已加白 · 📌 槽位 0 | `🌐 出口网段 203.0.113.0/24` |
| `notify_update=1`，网段变化 | 🔄 出口网段已更新 · 📌 槽位 0 | `🌐 203.0.113.0/24 → 192.0.2.0/24` |
| 未配置 token / 脚本出错 | ⚠️ 未配置 token / 💥 脚本出错 | 提示或错误信息 |

## 面板与运行行为

- 切换网络（`network-changed`）时立即执行，另按 `cron` 参数定时检查，面板可以手动刷新。
- 请求带 `policy: "DIRECT"`。本机切到全局代理模式也不会把代理出口写进槽位。这只管本机脚本发出的请求。如果别的设备经这台 Surge 网关出网，靠模块里的 `[Rule]` 让 API 直连。网关切到全局模式时这条规则不生效。
- 403 pinned 按成功处理。
- 网络错误和 HTTP 5xx 在 3s 和 8s 后各重试一次。429 不重试。
- `skip_ssid` 连着列出的 Wi-Fi 时不请求，面板显示「已跳过」。
- 格式不对的 token 显示为失败项，不会被静默忽略。错误文本里的 token 显示为 `pgnfw_***`。

手机填 `skip_ssid` 是为了避免家宽换 IP 后的竞态。如果手机在家先于路由器请求，新家宽网段会被钉进手机的槽位，路由器之后收到 403，家宽槽位留着旧网段。手机出门后它的槽位换成蜂窝网段，家里断连到路由器下一次运行为止。

手机读不到 Wi-Fi 名时（Surge 没有定位权限）不会跳过。在家时面板没显示「已跳过」就检查这个权限。
